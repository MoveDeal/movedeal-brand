# MoveDeal Brand Kit

Official brand assets for **MoveDeal** (movedeal.app) — the European moving marketplace.

Vector masters match the live product mark (`/images/movedeal-logo.png`): left-facing van, AI chip, leaf, Ocean `#0077B6`. Production SVGs are **fill-based** with **outlined Inter Bold** — no live `<text>`, no editor strokes.

## View locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Regenerate assets

```bash
npm install
node scripts/generate-assets.mjs
```

## Identity

- **Mark:** Delivery van + AI chip + leaf (Ocean `#0077B6`)
- **Lockup:** 32px mark · 8px gap · 24px Inter Bold (as on movedeal.app)
- **Colors:** Ocean, Tide, Signal, Ink, Paper (aligned with product UI)
- **Type:** Inter Bold for the wordmark; Inter for product UI
