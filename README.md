# MoveDeal Brand Kit

Official brand assets for **MoveDeal** (movedeal.app) — the European moving marketplace.

## View locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Regenerate assets

```bash
npm install
node scripts/generate-assets.mjs
```

## Identity

- **Mark:** Delivery truck + AI chip + leaf (Ocean `#0077B6`)
- **Colors:** Ocean, Tide, Signal, Ink, Paper (aligned with product UI)
- **Type:** Outfit (+ Source Serif 4 for short taglines only)

## GitHub Pages

Intended host: `https://movedeal.github.io/movedeal-brand/` (MoveDeal org).
